# Packed diagnostics

Default-off game feature `packed-diagnostics` plus secondary `MAYBRAID_PACKED_GROVE_METRICS=1`. Clean v8 timing omits the crate and these systems. The v9 visibility addition changes no render admission, culling, geometry, buffers or phase decisions.

`packed_visibility_sample` runs once/second in Last after visibility/transform propagation. It explicitly includes Disabled proxies, groups own flags by live PREPARING/ACTIVE/RETIRED state, and counts eligible proxies independent of hidden/inherited/disabled flags. Selection prefers an ACTIVE non-shadow proxy with scene-layer match and raw geometric OBB intersection with the actual scene camera, without requiring prior draws. It reports a labeled active fallback if no geometric candidate exists. Evidence includes actual Mesh3d visibility class and main camera visible-list membership, raw sphere/OBB tests, own/ancestor flags, owner identity and a capped12-node chain (including RetiredHost). Disabled ancestry is evidence, not an assumption that Disabled automatically inherits.

An extracted sample/frame resource drives `packed_queue_sample` once per new main sample at render Cleanup. This is the same selected full MainEntity, not a new independent1Hz selection. It distinguishes optional packed component extraction from native RenderMeshInstances, material/prepared material, actual per-main-view Mesh3d visible class, specialization/pipeline readiness and unbatchable phase membership. Native lists use the exact main identity even when their render entity is PLACEHOLDER. Missing resources/classes are explicit; there are at most8 view rows. The render invocation counter is diagnostic schedule progress, not presented FPS.

Both are durable structured events with stable names, no per-node/per-instance tracing. Counts describe diagnostic frames, not benchmark timings. Visibility/queue evidence does not prove rasterized pixels or shader parity. Five focused tests cover target parsing/bounds selection, bounded buffer sampling, hidden/Disabled ancestry/filter behavior and native placeholder/main identity. V9 manifests advertise packed_visibility_diagnostics=true with both event marker proofs; old v8 diagnostics cannot supply this evidence. Source remains production-equivalent to clean v8 except this optional observer and its package dependency.
