# Kenney Input Prompts (excerpt)

Outline (negative-space) glyphs from [Kenney Input Prompts 1.4](https://kenney.nl/assets/input-prompts).

License: Creative Commons Zero (CC0). See `License.txt`. Credit “Kenney” / kenney.nl is appreciated, not required.

Vendored Double-style chips: Xbox **A** (menu Select / equip), **B** (menu Back), **X** (world interact, inventory drop, and gallery Edit), **Y** (swap gun), **View** (gallery Delete), **LB/RB** (inventory section paging), **left-stick press** (inventory drawer mode), **RB** (skill-map hold), **RT** (fire), keyboard **E** (drop / interact / gallery Edit), keyboard **Enter** (menu Select / equip), keyboard **Escape** (menu Back), and keyboard **Delete** (gallery Delete).

The additional Xbox **LB outline** and **left-stick press** files are from Kenney's Input Prompts pack (CC0), alongside the existing RB asset.
