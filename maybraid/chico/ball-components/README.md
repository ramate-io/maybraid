# `chico-ball-components`

Ball and planar canopy components ([RFC-183 §3.1.2](https://github.com/ramate-io/maybraid/tree/main/rfc/rfc-000-000-183-chico-vegetation/03-01-stalk-and-ball-stick-trees/02-ball-components/README.md)).

Depends on **`chico-sdf`**, so foliage volumes stay compatible with stick primitives and downstream **`chico-sbs-trees`** assembly.
