# Buddha's-hand tuft

Clustered upward “fingers” with a widening diamond cross-section — reads like a palm hand, not flat grass.

## Role

Compact ornamental clumps (palm-bush massing before dedicated fronds). Each finger is a 4-corner diamond ring stack with belly bulge and pointed tip.

## Construction

[`construction.rs`](construction.rs) — `BuddhaHandElement`, `BuddhaHandCluster`. Width curve from shared [`BellyTipProfile`](../profile.rs).
