# Item playground

Viewer for kit-assembled items. Starts with the shared firearm receiver and [`FirearmConcept`](../firearms/src/concepts.rs) parts socketed onto `body` / `barrel` / `grip`.

```bash
cargo run -p items-playground
```

Press `/` then `show bullpup` (or `silopup`, `laznard`, …). `L` toggles look. WASD + Space fly.
