# Firearm intelligence

Higher-order firearm combatant brains.

- [`FirearmSpotting`](src/target.rs) lists candidate enemies. Each frame `vision` is a total ray budget. Candidates are ranked (closer first; `focus` sticky-biases the engaged target the same way fire targeting does), then that budget is split geometrically so a focused shooter spends almost all rays on the top target and an unfocused one shares them. Each probe still samples the capsule in priority order (center, head, hips, and sides) and remembers a **visible** aim point. Raycasts ignore an origin already inside Fixed geometry so camped eyes/muzzles are not instantly blind. Observations whose entity left the candidate list are dropped (a respawned player is not a ghost).
- [`FirearmIntelligence`](src/combat.rs) fields `FirearmObjective(Vec<SpottedTarget>)`: accuracy, tracking rate, motion-tracking skill, counter-recoil skill, headshots, vision, focus, trigger happiness, wall firing, spotting memory, and fire freshness. It solves desired aim from the **stock** (the pose pivot) toward the live capsule, then moves [`PlayerLook`](../../../player/src/identity.rs) toward that target at the configured angular rate. Motion tracking makes perceived aim trail a moving target by 300 ms at zero skill down to 30 ms at full skill; fire alignment uses that same perceived point so low-skill shooters place shots behind instead of waiting for perfect live alignment. Recoil displacement survives the next aim tick and decays only after the skill-scaled reaction delay / recovery half-life. Fire still checks the posed muzzle. Alignment is against the capsule, not a remembered sliver; an acquired trigger only remains held through the bounded alignment grace. `trigger_happiness` is the acquire delay.
- [`FirearmMovementIntelligence`](src/movement.rs) fields `FirearmMovementObjective(Vec<SpottedTarget>)`: range, cover, flee, and vantage. It hunts spotting candidates from their live positions even without a current sightline. If the combat brain does not have a fresh sightline, hide is lowered and sightline weight is raised so the mover leaves a glued cover hole.

Look and hunt may use last-known poses for `target_spotting_memory`. Combat still needs a spotted observation to aim, and a **fresh** one to fire.
