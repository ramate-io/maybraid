# `comproc`

Shared procedural primitives used across Maybraid: **guillotine** partitions and **noise** sampling.

Durham Jersey stamps are the current in-tree consumer (`Guillotine`, `Bounds2`, `NoiseConfig`). SDF mesh / ball-stick builders that used to live here were retired with the old `procedures/` stack.

Sibling crate: [`procedural-common`](../common/).
