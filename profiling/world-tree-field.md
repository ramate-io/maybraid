# Storybook tree field trial

This branch connects the tree field from Maybraid [#1647](https://github.com/ramate-io/maybraid/pull/1647) to one explicitly selected natural Temperate Lower Massives grove tile. The game defaults to its current grove renderer. The opt-in routes the existing Storybook placements through the field's CPU-generated skeleton and vertex-generated geometry. Oak, Rory, understory, terrain, material profiles outside the field, and the world seed stay on their existing paths.

Set `MAYBRAID_EXPERIMENT_TREE_FIELD_TILE=x,z` to a world XZ point inside the admitted grove tile. The half-open grove bounds select one tile. Set `MAYBRAID_EXPERIMENT_TREE_FIELD=gpu` for compute selection and indirect draw, or `cpu` for CPU selection and direct draw from the same descriptors. Both use the normal world and player spawn. Use the same settings, seed, location, camera and ordinary player route with the mode setting omitted for the legacy-renderer control. Keep the tile coordinate in that control to log the same generated placement digest. Keep `MAYBRAID_SHADOWS=off` on all arms. The custom tree shader has no matching shadow-cast and shadow-receive pass, so this trial only compares shadow-disabled rendering.

A legacy-only scout can set `MAYBRAID_EXPERIMENT_TREE_FIELD_SCOUT=1` and omit the mode. It logs the first naturally loaded High LOD tile with 4–64 Storybook trees, its bounds and the number of woody plants. Use the logged center for the paired arms and verify that both actually render the selected tile.

Set `MAYBRAID_EXPERIMENT_TREE_FIELD_AREA=3x3` to include the anchor's tile and the eight neighboring 100 m tiles. Use the same area setting in the legacy control. The selected neighborhood stays fixed while the player walks. Each High or Medium tile records its own naturally grown Storybook count and placement digest. A tile beyond 36 Storybooks retains its kits. This caps the common field at 324 trees, 12,960 branches and 165,888 leaves. Before kit replacement, the adapter checks that the largest buffer and the largest compute dispatch fit the actual device. During a warm LOD overlap, one patch represents each authored plant slot.

The selected trees retain their exact authored root, nominal height, grown variant seed, typed collision producer and existing shadow proxy. The field replaces the wood and canopy representation, including different branch topology, shader and LOD. A legacy-versus-field comparison measures that replacement. The CPU-versus-GPU field comparison holds descriptors and draw geometry constant and changes selection and submission. The existing forest generation and ground cover run in every arm. No grass or bush field renderer is installed by this trial.

The single-tile mode caps admission at 64 Storybook plants. An unsupported renderer keeps the current visual kits. The field reserves enough per-LOD entries for the worst-case admitted plant count. A native result needs a nonempty admitted naturally generated tile, exact placement/count parity, matching requested and actual selection mode, nonzero wood and canopy descriptor counts for all selected plants, both camera draw commands encoded, and a full forest image. Indirect command encoding does not read back GPU instance counts. The world trial disables the playground's CPU mirror, so that diagnostics do not run a second selector in the GPU arm. Report initial shader readiness separately from steady work. The existing field still rebuilds CPU descriptors for every changed membership and recreates upload buffers on each new generation. Frame extraction shares each unchanged descriptor snapshot.

The source fixtures cover renderer control parsing, placement and visibility lifetime, descriptor snapshot reuse and distinct presenter identity. Native Metal verified the single-tile legacy, CPU field and GPU field views with four matching Storybook placements. Dense-area native validation, timing and memory measurement are pending.
