# 3.1.10: Leaf Shading

This page is subsection **3.1.10** of [RFC-183: Chico Vegetation](../../README.md)


Leaf shading follows the same world-space palette approach as [Stick Shading](../09-stick-shading/README.md#319-stick-shading), but adds time, longitude, and altitude controls. The goal is to support stable foliage variation, seasonal color changes, snow accumulation, spring buds, and localized flecking without changing the underlying vegetation geometry.
