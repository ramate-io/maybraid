# 3.4.4.2: Tall Grass

- Use [Tuft](../../../03-01-stalk-and-ball-stick-trees/03-01-02-ball-components/03-01-02-06-tufts/README.md) construction. 
- Tall grass stalks (50 - 100cm) tufts coming in a few different varietals (not just one color mix). (We will be reserving really tall grass for understory.)
- Dense placement. 

Good in tropical and implied riverine areas.
