# 3.4.4.5: Tropical Tufts

- Use [Tuft](../../../03-01-stalk-and-ball-stick-trees/03-01-02-ball-components/03-01-02-06-tufts/README.md) and small [Palm Bush](../../../03-01-stalk-and-ball-stick-trees/03-01-07-well-known-tree-constructions/03-01-07-10-palm-bush/) constructions.
- Tall (25-50cm) tufts coming in lush and vibrant varietals. 
- Sparse placement. Lushness should come from surrounds.
