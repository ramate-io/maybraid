# 3.4.4.4: Wild Grass

- Use [Tuft](../../../03-01-stalk-and-ball-stick-trees/03-01-02-ball-components/03-01-02-06-tufts/README.md) construction. 
- Tall grass stalks (50 - 100cm) tufts coming in many different colorful varietals. 
- Dense placement. 

Good in valleys, prairies, tropics, and fields.
