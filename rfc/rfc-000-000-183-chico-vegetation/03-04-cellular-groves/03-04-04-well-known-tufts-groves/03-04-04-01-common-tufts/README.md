# 3.4.4.1: Common Tufts

- Use [Tuft](../../../03-01-stalk-and-ball-stick-trees/03-01-02-ball-components/03-01-02-06-tufts/README.md) construction. 
- Low to moderate grass (10-50cm) tufts coming in a few different varietals (not just one color mix).
- Low density. 

Good for overlaying detail on existing ground cover. Use when ground cover likelihood is high. 

Also, good as the only grass in arid regions.
