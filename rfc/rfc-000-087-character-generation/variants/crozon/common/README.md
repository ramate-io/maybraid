# Crozon common shape primitives

These folders hold **feature-agnostic** definitions: semantics, parameters, and (when present) reference art. The same primitive can appear under several Crozon **feature** trees (lower limb, upper limb, tail, horn, etc.); each feature folder links here and adds **embedding notes** (anchors, typical orientation, silhouette).

| Primitive | Definition | Crozon uses (current) |
|-----------|------------|-------------------------|
| [Bicylinder](./bicylinder/README.md) | Twin shafts merged–diverge–merge | [Lower limb](../lower-limb/bicylinder/README.md) |
| [Bow](./bow/README.md) | Curved spine with width profile | [Lower limb](../lower-limb/bow/README.md) |
| [Chain of pearls](./chain-of-pearls/README.md) | Spheroids on a spine | [Lower limb](../lower-limb/chain-of-pearls/README.md) |
| [Cylinder](./cylinder/README.md) | Straight extrusion; optional lateral wall pinch/flare | [Lower limb](../lower-limb/cylinder/README.md), [Neck](../neck/cylinder/README.md) |
| [Drum prong](./drum-prong/README.md) | Drumstick trunk + forked distal prongs | [Lower limb](../lower-limb/drum-prong/README.md) |
| [Drumstick](./drumstick/README.md) | Cylinder + bulbous region | [Lower limb](../lower-limb/drumstick/README.md), [Torso](../torso/drumstick/README.md) |
| [Spheroid](./spheroid/README.md) | Ellipsoid / sphere lump | [Torso](../torso/spheroid/README.md) |
| [Square Pyramid](./square-pyramid/README.md) | Square base → apex | [Lower limb](../lower-limb/square-pyramid/README.md), [Nose–snout](../nose-snout/square-pyramid/README.md) |
| ["Tapered Cuboid"](./tapered-cuboid/README.md) | Cuboid bulge + box taper (torso-friendly) | [Torso](../torso/tapered-cuboid/README.md) |

Add a row and a short **feature** stub whenever a primitive is reused (e.g. upper limb, tail, horn).
