# Rounded cone — Crozon horn

**Canonical primitive:** [Rounded cone (common)](../../common/rounded-cone/README.md)

## Horn embedding

Use for horns that should read **tapered and directional** but not needle-sharp. Keep the broad end seated at the skull socket and orient the rounded narrow end outward/upward per species; `taper_curve` controls whether thickness drops quickly near the base or gradually along the horn.

Compared with [cylinder](../cylinder/README.md), this gives a stronger natural taper; compared with [curling-cone](../curling-cone/README.md), this is typically cleaner and less spiral-forward.
