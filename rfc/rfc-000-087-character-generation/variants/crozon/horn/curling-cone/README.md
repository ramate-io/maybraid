# Curling cone — Crozon horn

**Canonical primitive:** [Curling cone (common)](../../common/curling-cone/README.md)

## Horn embedding

**Spiral** or **recurved** horns: root at the **boss** on the brow or ridge; `arc_angle` and `spine_length` control **ram** vs **springbok** vs **fantasy** corkscrew. Pair with species **symmetry** (mirrored instances, optional phase offset so left/right curls are not identical when seeded).

Keep **tip_radius** small for **sharp** hazards in animation bounds; raise it for **blunt** cartoon horns. For **double** curls, use **two** curling-cone meshes or a future “compound spine” extension—do not overload one spine with self-intersection without documenting collision rules.
