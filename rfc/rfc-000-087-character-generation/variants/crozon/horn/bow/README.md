# Bow — Crozon horn

**Canonical primitive:** [Bow (common)](../../common/bow/README.md)

## Horn embedding

**Curved** ram, **ibex**, or **tusk-like** sweep: spine arcs in a **sagittal** or **coronal** plane from the **root** socket. Width profile can swell at the **curve** for **weight** read. Pair with **trim** caps (optional extra mesh) at the tip for damage states.
