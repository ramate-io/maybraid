# Square pyramid — Crozon horn

**Canonical primitive:** [Square pyramid (common)](../../common/square-pyramid/README.md)

## Horn embedding

**Faceted** or **crystalline** horns: **apex** away from the skull, **base** at the **boss** on the brow or ridge. `twist` staggers the facet read in **pairs** for symmetry. `apex_blunt` yields **stub** mineral horns without a needle tip.
