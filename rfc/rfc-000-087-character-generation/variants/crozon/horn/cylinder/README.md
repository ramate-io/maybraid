# Cylinder — Crozon horn

**Canonical primitive:** [Cylinder (common)](../../common/cylinder/README.md)

## Horn embedding

**Straight** spike or **bovid** horn: axis from **skull socket** outward; taper can be faked with **stacked** cylinders of decreasing radius (multi-mesh) or a future dedicated taper field. Mirror for paired horns with a **symmetry** policy from the species spec.
