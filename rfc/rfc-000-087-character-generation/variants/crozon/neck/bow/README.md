# Bow — Crozon neck

**Canonical primitive:** [Bow (common)](../../common/bow/README.md)

## Neck embedding

**Swan** or **S-curve** neck: spine arcs in the **sagittal** plane from **torso** to **head**; width profile can narrow at the **inflection** for **graceful** read. End caps must align with [head-shape](../../head-shape/README.md) and [torso](../../torso/README.md) sockets so rig twist does not shear.
