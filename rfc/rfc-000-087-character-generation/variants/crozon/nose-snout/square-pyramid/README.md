# Square pyramid — Crozon nose and snout

**Canonical primitive:** [Square pyramid (common)](../../common/square-pyramid/README.md)

## Nose–snout embedding

A compact **square pyramid** is a strong match for a **beak**, **hard wedge snout**, or stylized **tapering muzzle**: wide attachment at the **face** (base), **apex** toward the tip of the bill or nose. Orient the pyramid axis along the species’ **bite** or **facial forward** direction; use `twist` so a square base diamond aligns with upper jaw width vs depth.

`apex_blunt` softens the tip for **duck-like** or **boxy** beaks without adding a separate cap mesh. Keep **base_width** / **base_depth** consistent with the [head-shape](../../head-shape/README.md) muzzle slice, so the seam stays art-directable.

For **non-avian** snouts, the same primitive can suggest **ceratopsian** or **turtle** front profiles at low poly counts; pair with mouth variants that terminate **inside** or **below** the apex for opening shots.
