# Drumstick — Crozon nose and snout

**Canonical primitive:** [Drumstick (common)](../../common/drumstick/README.md)

## Nose–snout embedding

**Bulbous snout** + **shaft** (pig, tapir, stylized **muzzle**): **bulge** at **nasal** root, **shaft** toward the lip line. Reuses drumstick **taper** vocabulary for **nostril flare** vs **narrow** tip; seam to [mouth](../../mouth/README.md) at the **distal** end.
