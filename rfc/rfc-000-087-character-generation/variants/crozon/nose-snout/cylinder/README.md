# Cylinder — Crozon nose and snout

**Canonical primitive:** [Cylinder (common)](../../common/cylinder/README.md)

## Nose–snout embedding

**Round muzzle** or **trunk** stub: axis along **facial forward**; `width`/`depth` for **circular** cross-section. **Lateral wall bow** can **flare** at the **nostril** ring or **pinch** behind the nose for **seal**/**canid** reads.
