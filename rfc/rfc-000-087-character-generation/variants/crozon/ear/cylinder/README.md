# Cylinder — Crozon ear

**Canonical primitive:** [Cylinder (common)](../../common/cylinder/README.md)

## Ear embedding

**Tube / funnel** ears: axis from **canal** outward; thin `width`/`depth` for **bat** or **rabbit** stand-ins at low poly. **Lateral wall bow** can flare the **distal** rim (trumpet) or pinch mid-tube for **notched** silhouettes.
