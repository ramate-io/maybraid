# Square pyramid — Crozon ear

**Canonical primitive:** [Square pyramid (common)](../../common/square-pyramid/README.md)

## Ear embedding

**Triangular fin** or **alert wedge** ear: small **flattened** pyramid parented **lateral** on the head; **profile** shows the **ridge**; front view reads as a **narrow V**. Prefer **low** `height`, so the ear does not read as a horn—use [square pyramid horn](../../horn/square-pyramid/README.md) scale language only if the species intentionally blurs ear/horn.

Combine with [dish](../dish/README.md) (concha) **medial** to the pyramid for volume; use [curling-cone](../curling-cone/README.md) if the tip should **roll** instead of staying planar.
