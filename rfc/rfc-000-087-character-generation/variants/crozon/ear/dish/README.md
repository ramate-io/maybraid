# Dish — Crozon ear

**Canonical primitive:** [Dish (common)](../../common/dish/README.md)

## Ear embedding

**Concha / cup** pinna: place the **opening** roughly **lateral** on the [head-shape](../../head-shape/README.md), **cavity** aimed at the **meatus** (or stylized canal opening). Shallow `depth` reads as a **flat** human-style concha; deep + narrow rim suggests **funnel** or **bat** ear bases.

Layer **outward** meshes ([cylinder](../cylinder/README.md) helix, [spheroid](../spheroid/README.md) lobe) as siblings or children; keep the **dish** as the **primary** volume that catches silhouette from the front three-quarter view.
