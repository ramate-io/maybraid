# Spheroid — Crozon ear

**Canonical primitive:** [Spheroid (common)](../../common/spheroid/README.md)

## Ear embedding

**Round lobe** or **pom** ears: single ellipsoid attached at **side** of [head-shape](../../head-shape/README.md); squash `rz` for **disk** ears or keep round for **mouse**/**bear** nubs. Stack **two** spheroids (multi-mesh) for **padded** tips vs narrow bases.
