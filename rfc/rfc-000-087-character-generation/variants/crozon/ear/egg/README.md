# Egg — Crozon ear

**Canonical primitive:** [Egg (common)](../../common/egg/README.md)

## Ear embedding

**Pod** or **teardrop lobe:** small egg parented **lateral** on the head; **narrow** tip toward **tragus**/**meatus**, **wide** end outward for a **plump** lobe read. Pairs well with [dish](../dish/README.md) (concha) **medial** to the egg. Axis often **tilted** slightly **back**, so the silhouette matches **drop** earrings at low poly.
