# Drumstick — Crozon torso

**Canonical primitive:** [Drumstick (common)](../../common/drumstick/README.md)

## Torso embedding

Orient **`height`** along the **spine** (typically **top** toward shoulders/neck socket, **bottom** toward pelvis/hip ring). The **bulge** reads as **rib cage / chest barrel**; the **shaft** narrows toward the waist or blends into pelvis geometry. Good for soft, animal-like or humanoid **tapered trunk** silhouettes without hard corners.

Match **width** / **depth** to shoulder span vs hip width rules for the species; use `bulge_width_taper` and `offset`, so the widest ring sits where concept art places the chest, not floating at the clavicle unless intended.
