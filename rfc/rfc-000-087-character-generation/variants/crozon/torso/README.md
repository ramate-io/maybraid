# Crozon torso variant multi-meshes

Torso kits reuse primitives from [`../common/`](../common/README.md). Each row links to the **canonical spec**, then to **torso-only** embedding notes.

| Primitive | Common definition | Torso (Crozon) |
|-----------|-------------------|----------------|
| Drumstick | [`common/drumstick`](../common/drumstick/README.md) | [`torso/drumstick`](./drumstick/README.md) |
| Tapered cuboid | [`common/tapered-cuboid`](../common/tapered-cuboid/README.md) | [`torso/tapered-cuboid`](./tapered-cuboid/README.md) |
| Spheroid | [`common/spheroid`](../common/spheroid/README.md) | [`torso/spheroid`](./spheroid/README.md) |

Add rows when you wire additional common shapes (e.g. [Cylinder](../common/cylinder/README.md)) into torso assembly rules.
