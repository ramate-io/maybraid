# Ellipsoid-capped square pyramid — Crozon torso

**Canonical primitive:** [Ellipsoid-capped square pyramid (common)](../../common/ellipsoid-capped-square-pyramid/README.md)

## Torso embedding

Works well for **tapered torsos** where you want directional wedge energy but no sharp apex. The curved edge flow and ellipsoidal terminal region support organic creature trunks while preserving a clear base-to-top taper.

For more angular silhouettes, increase `apex_contract` to approach a classic square-pyramid end state.
