# Tapered cuboid — Crozon torso

**Canonical primitive:** [Tapered cuboid (common)](../../common/tapered-cuboid/README.md)

## Torso embedding

Primary kit for **blocky** or **heroic** torsos: a **rectangular chest** that **tapers** to a narrower waist. Align **`bulge_width` / `bulge_depth`** to shoulder and chest depth; **`shaft_*`** at the **bottom** cap to the waist slice you will stitch to legs or a pelvis primitive.

Use **`corner_bevel`** sparingly to avoid reading as a [Cylinder](../../common/cylinder/README.md) with bow; keep faces **mostly** axial for low-poly readability. If front–back asymmetry matters (belly vs back), plan an asymmetric taper extension in the common spec later.
