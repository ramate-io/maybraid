# Rounded cuboid — Crozon torso

**Canonical primitive:** [Rounded cuboid (common)](../../common/rounded-cuboid/README.md)

## Torso embedding

Good default for **torso blocks** when you want clear chest/waist massing without hard mechanical edges. Keep `width` and `depth` broad in the upper section, then use modest `axis_taper` toward the pelvis for a natural trunk transition.

Compared with [tapered-cuboid](../tapered-cuboid/README.md), this keeps a similar rectangular read but with softer profile breaks that suit fleshy, stylized, or mildly creature-like builds.
