# Cylinder — Crozon lower limb

**Canonical primitive:** [Cylinder (common)](../../common/cylinder/README.md)

## Lower-limb embedding

Use for **thin** legs or arms. **Lateral wall bow** (see common spec) can suggest calf flare or a slight mid-shin pinch without switching to [Bow](../bow/README.md). Plain straight cylinders draw the eye when framed in close-up; pair with footwear, motion, or neighboring masses, or reserve for background creatures.
