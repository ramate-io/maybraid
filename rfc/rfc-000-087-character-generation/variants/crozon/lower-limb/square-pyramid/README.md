# Square pyramid — Crozon lower limb

**Canonical primitive:** [Square pyramid (common)](../../common/square-pyramid/README.md)

## Lower-limb embedding

Orient the **apex** toward the **foot** or **distal** joint so the limb **tapers** along the stance. **Tall** pyramids (large height vs base) suit lanky characters; **squat** ratios read stylized or juvenile. Faceted shading usually matches **geodesic** or hard-edge art direction better than smooth PBR.
