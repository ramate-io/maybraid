# Drumstick — Crozon lower limb

**Canonical primitive:** [Drumstick (common)](../../common/drumstick/README.md)

## Lower-limb embedding

The drumstick is a natural **leg** or **arm** segment: it mirrors many real distal limb volumes. Place it on the skeleton so **distal** maps to the next joint out (knee, ankle, wrist, etc.) and **proximal** to the parent joint; distal caps should line up with socket conventions from [RFC-88](/rfc/rfc-000-088-bevy-multi-mesh/README.md) when that API lands.
