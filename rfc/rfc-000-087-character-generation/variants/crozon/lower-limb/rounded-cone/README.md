# Rounded cone — Crozon lower limb

**Canonical primitive:** [Rounded cone (common)](../../common/rounded-cone/README.md)

## Lower-limb embedding

A strong default for **lower limbs** that should taper organically toward the distal end without a hard point. Use the broad end proximally (knee/elbow side) and the rounded narrow end distally (ankle/wrist side), with `taper_curve` controlling whether the mass drop happens early, mid-shaft, or late.

Compared with [drumstick](../drumstick/README.md), this offers a cleaner one-direction taper; compared with [cylinder](../cylinder/README.md), it avoids uniform-thickness reads.
