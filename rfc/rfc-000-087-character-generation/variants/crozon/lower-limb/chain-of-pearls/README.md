# Chain of pearls — Crozon lower limb

**Canonical primitive:** [Chain of pearls (common)](../../common/chain-of-pearls/README.md)

## Lower-limb embedding

Favors **rhythmic** silhouettes (larval, stylized insect-like, etc.) over a single muscle tube. Anchor **proximal** and **distal** rig sockets to the **first and last pearl centers** (or conservative hull bounds) so the bone chain length matches the visual beads.
