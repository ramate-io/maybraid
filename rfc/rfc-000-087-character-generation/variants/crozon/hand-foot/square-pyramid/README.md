# Square pyramid — Crozon hand and foot

**Canonical primitive:** [Square pyramid (common)](../../common/square-pyramid/README.md)

## Hand–foot embedding

Use a **flattened** pyramid (`height` modest vs base spans): parent **side-on**, so the **triangle profile** reads from the **lateral** view of the foot—**base** as the broad **pad / hoof ground contact**, **apex** toward **toe** tip, **heel**, or **outer edge** depending on species. Works for stylized **hoof shells**, **blade feet**, or **low-profile** paws where a [cylinder](../cylinder/README.md) digit row sits **distal** of the wedge.

Against the ground, keep **apex_blunt** if the tip must not intersect terrain collision; mirror for left/right feet with your symmetry policy.
