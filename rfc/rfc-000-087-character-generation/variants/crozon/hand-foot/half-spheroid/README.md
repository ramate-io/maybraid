# Half-spheroid — Crozon hand and foot

**Canonical primitive:** [Half-spheroid (common)](../../common/half-spheroid/README.md)

## Hand–foot embedding

**Palm** or **sole** contact surface: clip plane flush with **metacarpal** plane, so volume does not intersect the [upper limb](../../upper-limb/README.md) or [lower limb](../../lower-limb/README.md) cap. Orient dome **outward** from the body; pair with **cylinder** digits parented to the palm rim sockets.
