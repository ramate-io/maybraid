# Egg — Crozon hand and foot

**Canonical primitive:** [Egg (common)](../../common/egg/README.md)

## Hand–foot embedding

**Palm** or **sole** as an elongated pad: **wide** pole at **heel** or **wrist**, **narrow** toward **fingers** or **toes** for a **natural** hand blob; or a single **egg** metacarpal mass before [cylinder](../cylinder/README.md) digits. On feet, align **long_axis** with **arch** direction for **plantigrade** silhouettes.
