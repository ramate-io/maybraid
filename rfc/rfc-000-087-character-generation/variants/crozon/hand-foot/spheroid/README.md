# Spheroid — Crozon hand and foot

**Canonical primitive:** [Spheroid (common)](../../common/spheroid/README.md)

## Hand–foot embedding

**Paw pad** blob, **knuckle** swell, or **full** stylized **mitt** when fingers are not separated. Center slightly **forward** of the wrist for **plantigrade** feet; squash for **wide** tree-climber palms.
