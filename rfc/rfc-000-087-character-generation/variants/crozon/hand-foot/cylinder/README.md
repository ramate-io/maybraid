# Cylinder — Crozon hand and foot

**Canonical primitive:** [Cylinder (common)](../../common/cylinder/README.md)

## Hand–foot embedding

**Digit** segments: short `height` along **bone** axis; taper can be **per-instance** scale down the chain. **Toes** use the same recipe with smaller radii. For **hoof**, stack a **wide** short cylinder on a **narrow** distal stub (multi-mesh).
