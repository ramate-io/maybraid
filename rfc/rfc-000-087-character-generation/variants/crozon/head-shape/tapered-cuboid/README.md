# Tapered cuboid — Crozon head shape

**Canonical primitive:** [Tapered cuboid (common)](../../common/tapered-cuboid/README.md)

## Head embedding

**Blocky / heroic / low-poly** heads: wide **bulge** at brow/cheek, taper toward **jaw** or **muzzle plane**. Orient **`height`** along **spine-up** or **face-forward** per species; use `corner_bevel` to avoid looking like a literal crate. Jaw detail often belongs in [mouth](../../mouth/README.md); keep this volume as the **primary head mass** socket for features above.
