# Ellipsoid-capped square pyramid — Crozon head shape

**Canonical primitive:** [Ellipsoid-capped square pyramid (common)](../../common/ellipsoid-capped-square-pyramid/README.md)

## Head embedding

Good for **head shapes** that should feel exotic but controlled: broad square-derived base language, curved lateral edges, and a soft ellipsoidal terminal region instead of a horn-like point.

Dial `apex_contract` to move between softer cap reads, and sharper wedge reads; this lets one primitive cover both approachable creature heads and more severe profiles.
