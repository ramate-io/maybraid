# Spheroid — Crozon head shape

**Canonical primitive:** [Spheroid (common)](../../common/spheroid/README.md)

## Head embedding

**Round / cartoon cranium:** single ellipsoid or slight squash for **egg** or **bubble** heads. Parent center to **skull** joint; scale `rx`/`ry`/`rz` for species **brain case** proportions. Pair with separate [nose-snout](../../nose-snout/README.md) and [ear](../../ear/README.md) multi-meshes rather than stretching one sphere for everything.
