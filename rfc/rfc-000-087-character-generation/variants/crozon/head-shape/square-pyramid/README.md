# Square pyramid — Crozon head shape

**Canonical primitive:** [Square pyramid (common)](../../common/square-pyramid/README.md)

## Head embedding

**Flattish** pyramid as **crown**, **forehead block**, or **visor**: keep `height` **subtle** relative to `base_width` / `base_depth`, then **pitch** the mesh, so the **apex** sits **slightly below** the base’s forward tilt (**nose-down** / **brow-forward**) for a **sloped skull roof** instead of a vertical spire. Seat the **base** against the upper [spheroid](../spheroid/README.md) or [cylinder](../cylinder/README.md) mass, so the seam reads as **brow ridge** or **helmet brim**.

Use `twist` to diamond-align facets with [tapered-cuboid](../tapered-cuboid/README.md) corners if you merge volumes.
