# Rounded cuboid — Crozon head shape

**Canonical primitive:** [Rounded cuboid (common)](../../common/rounded-cuboid/README.md)

## Head embedding

Useful for **head blocks** that balance planar structure and soft anatomy. It reads less spherical than [spheroid](../spheroid/README.md) and less hard-edged than [tapered-cuboid](../tapered-cuboid/README.md), which makes it strong for stylized creatures and semi-realistic designs.

Use moderate `edge_radius` at brow, cheek, and jaw transitions so attached [mouth](../../mouth/README.md) and [nose-snout](../../nose-snout/README.md) parts seat cleanly without sharp seams.
