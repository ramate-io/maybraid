# Cylinder — Crozon tail

**Canonical primitive:** [Cylinder (common)](../../common/cylinder/README.md)

## Tail embedding

**Straight** tail or **mechanical** post: axis from **pelvis** back; short for **bunny** stub, long for **rat**. **Lateral wall bow** can add **subtle** side bulge; strong curves should use [Bow](../bow/README.md) instead.
