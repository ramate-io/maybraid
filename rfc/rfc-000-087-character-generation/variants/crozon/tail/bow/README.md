# Bow — Crozon tail

**Canonical primitive:** [Bow (common)](../../common/bow/README.md)

## Tail embedding

**Curved rest pose** (squirrel, fish, **scorpion** arch): single **bow** volume along **caudal** sweep; width profile can **swell** mid-tail for **muscle**. Root cap parents to **pelvis**; tip cap is free or hosts a [square-pyramid](../../common/square-pyramid/README.md) stinger (separate multi-mesh).
