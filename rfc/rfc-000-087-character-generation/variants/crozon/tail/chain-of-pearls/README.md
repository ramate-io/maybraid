# Chain of pearls — Crozon tail

**Canonical primitive:** [Chain of pearls (common)](../../common/chain-of-pearls/README.md)

## Tail embedding

**Flexible** tail: pearls from **pelvis** socket distally; **`radius_taper`** shrinks toward the **tip**. Overlap for **smooth** cable, gaps for **vertebra** look. Rig as **FK chain** matching `pearl_count`.
