# Crozon tail variant multi-meshes

Tails are often **chains** or **tapered** extrusions along a **caudal** axis. Kits from [`../common/`](../common/README.md):

| Variant | Common definition | Tail (Crozon) |
|---------|-------------------|---------------|
| Chain of pearls | [`common/chain-of-pearls`](../common/chain-of-pearls/README.md) | [`tail/chain-of-pearls`](./chain-of-pearls/README.md) |
| Bow | [`common/bow`](../common/bow/README.md) | [`tail/bow`](./bow/README.md) |
| Cylinder | [`common/cylinder`](../common/cylinder/README.md) | [`tail/cylinder`](./cylinder/README.md) |

**Multi-mesh:** taper can be **pearl radii** decreasing distally, or **stacked** cylinders with decreasing radius, parented along a spline.
