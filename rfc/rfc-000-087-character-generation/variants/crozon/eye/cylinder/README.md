# Cylinder — Crozon eye

**Canonical primitive:** [Cylinder (common)](../../common/cylinder/README.md)

## Eye embedding

**Stalk** or **periscope** eyes: short **cylinder** from **socket** to a distal **spheroid** globe (multi-mesh). Axis along **outward** normal from [head-shape](../../head-shape/README.md); thin radius for **crab**/**snail** tropes.
