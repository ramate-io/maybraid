# Egg — Crozon eye

**Canonical primitive:** [Egg (common)](../../common/egg/README.md)

## Eye embedding

**Almond** or **teardrop** eye volume: **long_axis** along **lateral** width of the orbit; **narrow** poles at **inner** and **outer** canthus (swap which is wider per species), or **vertical** almond with narrow points at **lid** creases. Use when [spheroid](../spheroid/README.md) reads too round for stylized humans or **reptile** slits projected into 3D mass.
