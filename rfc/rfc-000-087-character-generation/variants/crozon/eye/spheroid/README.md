# Spheroid — Crozon eye

**Canonical primitive:** [Spheroid (common)](../../common/spheroid/README.md)

## Eye embedding

**Eyeball** / **compound ommatidium** blob: center in **orbit**; squash for **lenticular** stylized eyes. For **stylized** characters, one spheroid can stand in for **globe + cornea**; add a **second** multi-mesh (rim torus or cap) for **lids** later.
