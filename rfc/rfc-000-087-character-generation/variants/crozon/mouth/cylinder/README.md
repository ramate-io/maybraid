# Cylinder — Crozon mouth

**Canonical primitive:** [Cylinder (common)](../../common/cylinder/README.md)

## Mouth embedding

**Simple oral tube** or **beak interior**: axis along **jaw opening**; short `height` for **closed** rest, or elongated for **proboscis**-adjacent stubs. Often **parents between** upper and lower jaw anchors; clip against [nose-snout](../../nose-snout/README.md) in CSG or with careful seam placement.
