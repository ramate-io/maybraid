# Variants

**Crozon** (RFC-87): start at [`crozon/common/`](./crozon/common/README.md) for shared mesh primitives; feature-specific embedding notes live under `variants/crozon/` (e.g. [`head-shape`](./crozon/head-shape/README.md), [`hand-foot`](./crozon/hand-foot/README.md), [`lower-limb`](./crozon/lower-limb/README.md), [`torso`](./crozon/torso/README.md), [`tail`](./crozon/tail/README.md), …). Most features list **≥3** variant recipes; many are **multi-mesh** compositions.
