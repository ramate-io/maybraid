# Drum Prong

Similar to [Drumstick](../drumstick/README.md) but with a split at the bottom into two curving cylinders. 

> [!NOTE]
> This will most likely be easiest to implement via the difference between a [Drumstick](../drumstick/README.md) and a cone-like shape, placed at the bottom. 

## As a Lower Limb

The Drum Prong is good for exotic creatures. It combines a familiar outline with forlorn detail.
